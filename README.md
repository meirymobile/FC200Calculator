# מחשבון פיננסי Casio FC-200V - כולל פתרונות מלאים ולוח סילוקין באקסל

סימולטור מקצועי ומדויק של המחשבון הפיננסי הידוע **Casio FC-200V (דור 2)**, בעיצוב שלדה שחורה מט יוקרתית ומקשי ניווט בצבע אפור-כחול (ללא כסף), יחד עם מרכז דוחות מתקדם המפיק פתרונות מתמטיים שלב-אחר-שלב, לוחות סילוקין אינטראקטיביים וייצוא מלא לקבצי אקסל (`.xlsx`).

---

## 🚀 תכונות עיקריות

### 1. הדמיית ממשק מלאה של Casio FC-200V
* **שלדה שחורה מט (Matte Black):** מראה מודרני, אלגנטי ונקי.
* **מקשי ניווט כחולים-אפורים (Blue-Gray REPLAY D-Pad):** ניווט מהיר בין משתנים ומצבי חישוב.
* **מסך LCD דו-שורתי אותנטי:** שורת Dot-Matrix עליונה לפרמטרים ותפריטים עם חיווי סטטוס (`SET:END`, `B`, `S`, `A`), ושורת תוצאות גדולה.
* **מקש SOLVE ייעודי:** פותר מיידית את הפרמטר המסומן ומפעיל את מנוע הפתרון המלא.

### 2. מצבי עבודה פיננסיים (Financial Modes)
* **`CMPD` (חישובי ריבית דריבית / TVM):**
  * $PV$ (ערך נוכחי / גובה הלוואה)
  * $FV$ (ערך עתידי / צבירה)
  * $PMT$ (תשלום תקופתי / שפיצר)
  * $n$ (מספר תקופות)
  * $I\%$ (שיעור ריבית שנתית)
  * תמיכה בעיתוי תשלום: תחילת תקופה (`Begin`) או סוף תקופה (`End`)
  * תמיכה מלאה בריביות מתואמות ($P/Y$ ו-$C/Y$).
* **`AMORT` (לוח סילוקין):**
  * יתרת קרן ($BAL$)
  * מרכיב קרן בתשלום ($PRN$)
  * מרכיב ריבית בתשלום ($INT$)
  * סה"כ קרן מצטברת שסולקה ($\sum PRN$)
  * סה"כ ריבית מצטברת ששולמה ($\sum INT$)
* **`CASH` (תזרים מזומנים וכדאיות השקעה):**
  * חישוב ערך נוכחי נקי ($NPV$)
  * שיעור תשואה פנימי ($IRR$)
  * תקופת החזר השקעה ($PBP$)
  * ערך עתידי נקי ($NFV$)
* **`CNVR` (המרות ריבית):**
  * המרה בין ריבית נקובה לריבית אפקטיבית ($APR \leftrightarrow EFF$).
* **`COST` (רווחיות ומסחר):**
  * חישובי $Cost$, $Sell$, $Margin\%$.
* **`COMP` (חישובים כלליים ומדעיים):**
  * ביטויים אריתמטיים, חזקות, שורשים, לוגריתמים וכו'.

---

### 3. מרכז דוחות, פתרונות וייצוא לאקסל
* **דרך פתרון מלאה ומפורטת:**
  * הסבר כלכלי ומתמטי של הבעיה.
  * הצגת נוסחת ערך הזמן של הכסף הרלוונטית.
  * ריכוז הפרמטרים מתוך המחשבון.
  * הצבה שלב-אחר-שלב והסבר התוצאה הסופית.
  * כפתור **"העתק פתרון"** להדבקה במסמכים או עבודות.
  * כפתור **"ייצא פתרון לאקסל (.xlsx)"**.
* **לוח סילוקין אינטראקטיבי:**
  * פירוט תקופה אחר תקופה (קרן, ריבית, יתרה, מצטברים).
  * סינון וחיפוש מהיר.
  * כפתור ייצוא ייעודי **"ייצא לוח סילוקין לאקסל (.xlsx)"** המפיק קובץ Excel מעוצב עם נוסחאות וסכומים כוללים.
* **ייצוא ל-PDF והדפסה ישירה:**
  * תמיכה בהדפסה נוחה בלחיצת כפתור אחת.

## 📱 התקנה ושימוש בכל הפלטפורמות

### 1. הרצה מקומית ודפדפן (Web)
```bash
# הרצת שרת פיתוח מקומי
npm run dev

# בניית גרסת פרודקשן
npm run build
```

### 2. התקנה ב-iPhone ו-iPad (PWA)
1. פתח את הכתובת בדפדפן **Safari** במכשיר.
2. לחץ על כפתור השיתוף (Share) בתחתית המסך.
3. בחר **"הוסף למסך הבית" (Add to Home Screen)** ולחץ על **הוסף**.
4. האפליקציה תותקן במסך מלא ועובדת בצורה חלקה גם ללא אינטרנט!

### 3. התקנה באנדרואיד ויצירת קובץ APK
* **התקנה מהירה בדפדפן:** פתח ב-Chrome ובחר בתפריט "התקן אפליקציה".
* **בניית קובץ APK מקומי:**
  הפרויקט כולל תשתית **Capacitor** מוגדרת. הרץ:
  ```bash
  npm run build
  npx cap sync
  npx cap open android
  ```
  בחלון ה-Android Studio שייפתח: לחץ בתפריט העליון על **Build > Build Bundle(s) / APK(s) > Build APK(s)** כדי לקבל קובץ `.apk` מוכן להתקנה ישירה על כל מכשיר אנדרואיד.
